<h1 align="center">TupiFlix</h1>
<p align="center">Uma plataforma de streaming para documentários relacionados ao folclore e à mitologia brasileira. </p>

## Sobre o Projeto
O objetivo do TupiFlix é valorizar e popularizar as lendas, personagens e tradições do folclore nacional, reunindo em um só lugar vídeos de qualidade sobre temas como Saci-Pererê, Curupira, Iara, Boitatá, Cuca, Lobisomem, Mula sem Cabeça, entre outros. A plataforma integra a API do YouTube para exibir documentários e vídeos relevantes, além de apresentar carrosséis temáticos e páginas especiais para cada lenda.

## Funcionalidades
- Busca e exibição de vídeos do YouTube sobre folclore e mitologia brasileira
- Carrossel de lendas em destaque
- Páginas temáticas para cada lenda urbana
- Visual moderno, responsivo e inspirado em plataformas de streaming
- Cards de vídeo com informações de título, canal, duração e data

## Tecnologias Utilizadas
- HTML5, CSS3 (com variáveis e responsividade)
- JavaScript (ES Modules)
- API do YouTube
- Font Awesome, Google Fonts
